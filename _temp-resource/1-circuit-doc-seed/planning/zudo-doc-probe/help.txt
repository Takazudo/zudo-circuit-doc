
Usage: create-zudo-doc [destination] [options]

  destination                  Directory to create the project in; may be a path
                               (e.g. sub/my-docs). Its last segment becomes the
                               project name. Default: my-docs

Options:
  --name <name>                Project name written to package.json. Overrides
                               the name derived from the destination's last segment
  --lang <code>                Default language (en, ja, zh-cn, zh-tw, ko, es, fr, de, pt)
                               Default: en
  --additional-langs <a,b>     Additional locale codes (ordered; implies i18n)
  --color-scheme-mode <mode>   single | light-dark
  --scheme <name>              Color scheme (single mode)
  --light-scheme <name>        Light scheme (light-dark mode)
  --dark-scheme <name>         Dark scheme (light-dark mode)
  --default-mode <mode>        light | dark (light-dark mode)
  --[no-]respect-system-preference
                               Respect OS color scheme preference
  --theme-pack <slug>          Theme pack (default, academia, bauhaus, beacon, blueprint, botanica, broadsheet, brutalist, drift, eink, fjord, foundry, futura-editorial, hearth, hollow, ledger, manuscript, matcha, nocturne, observatory, onyx, phosphor, riso, sakura, scandi, solar, sumi, swissgrid, tidepool, timberline, washi)
                               Default: default
  --[no-]i18n                   Configure additional locales
  --[no-]search                 Built-in client-side search
  --[no-]sidebar-filter         Real-time sidebar filtering
  --[no-]claude-resources       Auto-generate Claude Code docs
  --[no-]codex-resources        Auto-generate Codex docs (.codex/, AGENTS.md)
  --[no-]claude-skills          Ship zudo-doc-* Claude Code skills (design-system, translate, version-bump)
  --[no-]claude-skills-writing  Ship the zudo-doc-writing skill (doc-writing + navigation-structure guide for AI-assisted authoring)
  --[no-]design-token-panel     Interactive tabbed panel for tweaking spacing, font, size, and color tokens
  --[no-]theme-pack-switcher    Bottom-right flyout to switch between installed theme packs
  --[no-]sidebar-resizer        Draggable sidebar width
  --[no-]sidebar-toggle         Show/hide desktop sidebar
  --[no-]toc-toggle             Show/hide the desktop table of contents
  --[no-]versioning             Multi-version documentation support
  --[no-]doc-history            Show document edit history
  --[no-]body-foot-util         Right-aligned strip below each doc: doc history trigger + View source on GitHub link
  --[no-]llms-txt               Generate llms.txt for LLM consumption
  --[no-]skill-symlinker        Symlink documentation skills into Claude Code or Codex
  --[no-]tauri                  macOS desktop wrapper with in-page search
  --[no-]tauri-dev              Configurable desktop dev wrapper for any project
  --[no-]footer-nav-group       Navigation links in the footer
  --[no-]image-enlarge          Click-to-enlarge for oversized markdown images
  --[no-]asset-viewer           Viewer pages for files under public/assets
  --[no-]dynamic-page-transition SPA-style page transition with history handling
  --[no-]footer-copyright       Copyright notice in the footer
  --[no-]changelog              Changelog page
  --[no-]tag-governance         Vocabulary-aware tag audit + suggest scripts
  --[no-]doc-tags               Per-tag and tag-index browsing routes (docs/tags/...)
  --[no-]footer-taglist         Grouped tag index in the footer (requires tagGovernance)
  --[no-]noindex                Keep search engines out (noindex meta + robots.txt)
  --changelog-packages <a,b>  Per-package changelog pages (implies changelog)
  --github-url <url>           GitHub repository URL (drives header link + source link)
  --preset <path>              Load settings from a JSON preset file (use "-" for stdin)
  --pm <manager>               pnpm | npm | yarn | bun
  --[no-]install               Install dependencies after scaffolding
  --[no-]git                   Initialize a git repository + initial commit
                               (default: on; enables doc-history metadata)
  -y, --yes                    Use defaults for unspecified options, skip prompts
  -h, --help                   Show this help message

Examples:
  # Interactive mode (default)
  create-zudo-doc

  # Non-interactive with defaults
  create-zudo-doc my-docs --yes

  # Fully specified
  create-zudo-doc my-docs --lang ja --scheme "Default Dark" --no-i18n --pm pnpm --install

  # Scaffold into a subdirectory (package name: ref-doc)
  create-zudo-doc sub/ref-doc --yes

  # Per-package changelog pages
  create-zudo-doc my-docs --changelog-packages core,cli --yes
