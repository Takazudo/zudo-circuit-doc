## Open questions

| Question ID | Exact question | Why the answer matters | Evidence needed | Owner or next task |
|---|---|---|---|---|
| Not assigned | What should this circuit do, for whom, and under which constraints? | Every later choice depends on it | The owner's description | Next action 1 |

Classify the needed work in plain language: source research, identity resolution, calculation, design choice, asset audit, supplier information, or physical measurement. This makes it clear whether another web lookup can answer the question or a bench test is required.

## Handoff to the next session

Read the [project brief](./index.mdx) and this page, run `pnpm circuit:check`, then start next action 1. The expected artifact is a filled brief. For a larger delegation, copy the task-request template described in [How we work](./how-we-work.mdx).

When updating this page, remove stale imperative tasks that are already completed, keep historical work in its original decision or verification record, and carry forward only unresolved dependencies.
