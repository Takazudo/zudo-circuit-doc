## Purpose

| Field | Project statement |
|---|---|
| Project name | TMP1075 I²C temperature breakout |
| Intended user and setting | A developer evaluating a digital temperature sensor on a bench, connected to a microcontroller or single-board-computer host |
| What the object does | Reports the board temperature over I²C to the host |
| Why this project exists | To exercise the zudo-circuit-doc workflow on a small circuit with one exact component and a real manufacturer datasheet |
| What a successful first prototype demonstrates | The host reads plausible temperature values at the expected I²C address, and the reading can be compared against a reference thermometer |
| Current owner or maintainer | zudo-circuit-doc maintainers (example project) |

Scenario: the developer plugs the breakout's header into the host's I²C pins and the host's logic supply, scans the bus, finds the sensor at its strapped address and polls the temperature register. Reading the temperature is essential; the ALERT output, one-shot mode and conversion-rate tuning are later experiments.
