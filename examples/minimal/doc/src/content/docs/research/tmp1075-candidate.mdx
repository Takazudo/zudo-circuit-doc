## Candidate register

| Candidate record | Exact identity confirmed? | Why it is being considered | Material evidence gap | Current disposition |
|---|---|---|---|---|
| Texas Instruments TMP1075DR | Yes: SBOS854F addendum row TMP1075DR, SOIC (D), 8 pins | LM75-compatible pinout and software, SOIC package, own datasheet | Installed accuracy and self-heating need bench data | Selected |
| Texas Instruments TMP75AIDR | Yes: SBOS288M addendum (physical page index 24, printed "Addendum-Page 1") lists TMP75AIDR as Active, SOIC (D), 8 pins | Classic LM75-class part in SOIC | Shared-device datasheet; pin-table text defect (below) | Not selected |
| Texas Instruments TMP117 | Not checked | Higher-accuracy digital sensor | Package: a leadless small-outline package, against the hand-soldering preference (not re-verified in this task) | Not selected |
| Texas Instruments TMP102 | Not checked | Small, low-power digital sensor | Package: a very small SOT package, against the hand-soldering preference (not re-verified in this task) | Not selected |

TMP117 and TMP102 were rejected by package preference only. No source was retrieved for them in this task, so nothing on this page says they are unsuitable or unavailable.

| TMP75 pin table | Same document, physical page index 2, printed page 3, Pin Functions table, row SCL | The SCL row is typed as an input but its description reads "Open-drain output; requires a pullup resistor" — a text defect for a clock input | Research reading only |

## Datasheet and CAD needs

- Retained: TI SBOS854F revision F for TMP1075DR, hash-recorded in the owner bundle's sources.
- Acquired later (Workflow D): KiCad symbol, footprint and 3D model for the SOIC (D) package, fidelity family; the footprint is a generic JEDEC land pattern, compared with `fact-tmp1075-ti-land-pattern` in `fact-tmp1075-footprint-choice`.

## Recommendation and alternatives

TMP1075DR is recommended: it is TI's LM75-compatible sensor with its own datasheet, the supply range covers the host rail, and the SOIC package suits hand assembly. The strongest reason to choose differently would be a need for better accuracy than the TMP1075's guaranteed limits (`fact-tmp1075-accuracy-d-40-110`), which would favour a precision sensor such as TMP117 at the cost of a leadless package. Adopted in the [sensor selection decision](../decisions/sensor-selection.mdx).
