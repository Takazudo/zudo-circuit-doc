CLI commands, exit codes, and the `circuit.config.ts` configuration contract for
`@takazudo/zudo-circuit-doc`. Every command and flag on this page is taken from the real
`--help` output of the built CLI, not from the plan that preceded it — see
[Reference → CLI](./cli.mdx) if the two ever look different from what you'd expect.

## In this section

- [CLI](./cli.mdx) — every command, its flags, and its exit codes.
- [`circuit.config.ts`](./config.mdx) — every field, its default, and the validation errors the
  loader raises.
- [The generated project](./generated-project.mdx) — the exhaustive file-by-file layout and every
  root script.
- [Publication schemas](./schemas.mdx) — `selection.json`, `assets.json`, and the
  resolved-validator-config pointer.
- [Capability & tool matrix](./capability-matrix.mdx) — which external tools and network access
  each command needs, and what happens when one is missing.
