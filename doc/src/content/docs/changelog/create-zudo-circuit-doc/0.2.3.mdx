Released: 2026-11-12

Version 0.2.3 generates projects on the zudo-doc 10.0.3 / ZFB 6.0.1 family and pairs them with
[@takazudo/zudo-circuit-doc](../zudo-circuit-doc/0.4.0.mdx) `^0.4.0`. Projects generated by
earlier versions are unchanged; to move one, follow the
[0.3 to 0.4 migration recipe](../../concepts/ownership-and-upgrades.mdx).

## Other changes

- Generated projects select runtime `^0.4.0` and pin zudo-doc and zudo-doc-history-server
  10.0.3 and ZFB, zfb-runtime and zfb-md-wasm 6.0.1.
- Follow create-zudo-doc 10's generator for the doc host: `typescript ^7.0.2` and
  `diff ^8.0.4 || ^9.0.0`. Graphite stays the generated look.
