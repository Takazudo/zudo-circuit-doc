Released: 2026-11-07

Version 0.2.1 generates projects on zudo-doc 9.1.4 and switches new projects to Graphite,
zudo-doc 9's default look. The runtime pairing is unchanged: generated projects still select
[@takazudo/zudo-circuit-doc](../zudo-circuit-doc/0.3.0.mdx) `^0.3.0` and ZFB 5.2.2.

## Features

- Generate `themePack: "graphite"` with `themePacks: ["graphite"]` in `doc/zfb.config.ts`, so
  new projects follow zudo-doc's current look in light and dark. The allowlist keeps the other
  bundled theme packs out of the build.
- Pin zudo-doc, zudo-doc-history-server and the vendored create-zudo-doc scaffold provenance to
  9.1.4. The upstream scaffold parity check passes with no host-file changes.

## Other changes

- Projects generated by 0.2.0 keep the Classic look (`themePack: "default"`). To adopt
  Graphite, follow the
  [ownership and upgrades guide](../../concepts/ownership-and-upgrades.mdx).
