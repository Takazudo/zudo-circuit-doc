Released: 2026-11-07

Version 0.2.0 generates projects on the published zudo-doc 9.1.3 / ZFB 5.2.2 family together
with runtime [@takazudo/zudo-circuit-doc 0.3.0](../zudo-circuit-doc/0.3.0.mdx), following the
[#156](https://github.com/Takazudo/zudo-circuit-doc/pull/156) migration.

## Breaking changes

- Require Node 24 LTS (`>=24 <25`), matching zudo-doc 7 and later. Node 22 and 25 are unsupported.
- Generate the zudo-doc 9.1.3 / ZFB 5.2.2 host and select runtime `^0.3.0`. The generated pins
  are zudo-doc/history/create-zudo-doc 9.1.3 and the aligned ZFB 5.2.2 tuple, matching the
  runtime peer floors `^9.1.3` / `^5.2.2`.

## Other changes

- Projects generated by 0.1.0 stay on runtime `^0.2.0` with zudo-doc 5 / ZFB 2 until their host
  migration is intentional; follow the
  [existing-consumer migration recipe](../../concepts/ownership-and-upgrades.mdx).
- Verify the scaffold against the published runtime with strict packed-consumer types, build,
  browser, and fixture checks.
