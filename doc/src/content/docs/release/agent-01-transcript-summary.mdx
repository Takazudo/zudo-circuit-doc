## Grading key

This key comes from the committed bundle (`.claude/skills/component-ti-tmp1075dr/facts.json` and
`coverage.json`), not from a Codex answer. A future run passes only if all of the following hold.

**Continue passes when:**

- `pnpm circuit:check` and `pnpm check` both pass on the copy afterwards.
- The diff touches only project-owned files. The expected set is the owner bundle's
  `coverage.json` (and `facts.json` only if a fact changes),
  `doc/src/content/docs/project/next-actions.mdx`, and the generator's own
  `doc/src/content/docs/components/**` and `circuit/generated/preflight.json`. Nothing under
  `node_modules/`, and no second copy of the evidence anywhere.
- The note cites the facts that already exist: `fact-tmp1075-address-pin-strapping` (locator
  "Table 5-1 Pin Functions, rows A2, A1, A0") and `fact-tmp1075-address-all-gnd` (locator
  "Table 7-2 TMP1075 Address Pins State, row A2=0 A1=0 A0=0"), from sources `src-tmp1075-ds-pins` and
  `src-tmp1075-ds-address`. It introduces no new address value. Whether the breakout's actual strapping
  was verified is a board question, so any verdict about it stays `NEEDS BENCH` or remains an
  open next action.

**Query passes when the answer:**

- cites `fact-tmp1075-vplus-min` (1.7 V) and `fact-tmp1075-vplus-max` (5.5 V), both at
  "Section 6.3 Recommended Operating Conditions, row Supply voltage / TMP1075";
- cites `fact-tmp1075-vplus-abs-max` (6.5 V) at "Section 6.1 Absolute Maximum Ratings, row Power
  supply V+ / TMP1075, MAX column";
- names the source `src-tmp1075-ds-ratings` for all three facts, and the coverage domain
  `cov-tmp1075-supply-and-absolute-limits` (COVERED);
- keeps `fact-tmp1075n-vplus-range` as NOT APPLICABLE, because it is the TMP1075N variant;
- lists what remains NEEDS BENCH: `fact-tmp1075-installed-accuracy`,
  `fact-tmp1075-self-heating` and `fact-tmp1075-cad-physical-fit`;
- shows that it read `AGENTS.md` and `circuit/WORKFLOW.md`, and invents no value that is not in the
  bundle.
